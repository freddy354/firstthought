Entry for the [make.fun bounty "One Word, First Thought"](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8).

The program writes exactly one word to `/output/entry.txt` — the first word that comes to mind. The word is **Defenestrate**: to throw someone (or something) out of a window. A Latinate, bureaucratic verb for a piece of slapstick violence — surprising, vivid, and it rewards a second look.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Output: `Defenestrate` (12 characters, no trailing newline).
